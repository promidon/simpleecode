# Repository agent instructions

Before any remote, branch, worktree, history, push, pull-request, tag, release,
or GitHub-settings operation, read and follow the binding
[GitHub repository workflow](docs/github-repository-workflow.md).

Always verify the current branch, worktree cleanliness, remote destinations,
and relevant ancestry before acting. Never infer permission to publish, rewrite
history, delete refs, or include unrelated work.

For implementation work, also follow
[engineering principles](docs/engineering-principles.md) and
[UX design principles](docs/ux-design-principles.md).
