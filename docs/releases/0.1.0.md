# SimpleeCode 0.1.0 — first public beta

SimpleeCode explains your real code in plain language, then gives you direct
links back to the files and lines so you can check the answer yourself.

This first public beta includes deterministic code facts, Explain, Tour and
Check flows, privacy review before sending, secret redaction, and a
checksum-verified updater that runs only when you choose it.

Download the VSIX from <https://simpleecode.netlify.app/download>, then use
**Extensions → ··· → Install from VSIX…** in VS Code. The source is available
under GPL-3.0-or-later at <https://github.com/promidon/simpleecode>.

Requires VS Code 1.90 or later. Installing `claude-code-acp` enables live
streaming; without it, SimpleeCode falls back to a clipboard-based flow.
