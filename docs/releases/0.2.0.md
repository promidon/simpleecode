# SimpleeCode 0.2.0

This release rebuilds the explanation journey around goals and optional
guidance. Select code, prepare Understand / Connections / Investigate, then
explicitly send. Use ELI5 or describe your background without changing privacy
permissions. Save a device-local default only when you choose.

The full prompt is inspectable inside the sidebar before and after sending.
Blocking review dialogs are removed. Extra review defaults off, while explicit
true settings retain an inline approval step.

Follow-ups use the captured code and guidance. Opening a different editor does
not change the subject. Source, goal, guidance and privacy changes start a fresh
explanation. Stop preserves incomplete output. External chat handoff is explicit
and cannot confirm delivery or verify answers automatically.

The extension identity and update settings are unchanged. Startup update checks
remain opt-in. Download the VSIX from <https://simpleecode.netlify.app/download>,
install it with **Extensions → ··· → Install from VSIX…**, and reload VS Code, or
use **SimpleeCode: Check for Updates** from 0.1.0.
