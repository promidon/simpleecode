# SimpleeCode 0.2.1

This update makes the Explain sidebar easier to read. Setup lives in one card
that folds into a one-line summary once an answer arrives, so the answer comes
first. Tables in answers render properly, sources show short project paths
grouped by file, and statuses read in plain language.

The answer check no longer flags language keywords such as `struct` or `nil` as
unverified, so its warnings point at names worth checking. Download the VSIX
from <https://simpleecode.netlify.app/download>, install it with
**Extensions → ··· → Install from VSIX…**, and reload VS Code, or use
**SimpleeCode: Check for Updates**.
