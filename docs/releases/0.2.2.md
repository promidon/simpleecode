# SimpleeCode 0.2.2

The Explain sidebar now works like a chat window. It fills the full height of the
sidebar and resizes with VS Code, and the follow-up box sits at the bottom.
When you press Explain, both the setup and Context & facts fold into one-line bars
pinned at the top, so the answer gets the room, and each new answer starts right
under them so you can read from the first line.

Download the VSIX from <https://simpleecode.netlify.app/download>, install it with
**Extensions → ··· → Install from VSIX…**, and reload VS Code, or use
**SimpleeCode: Check for Updates**.
