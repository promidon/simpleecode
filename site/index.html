Three clear jobs

Understand the code in front of you.

01

Explain

Select code, a function, or a whole file. Get a plain-language explanation grounded in its symbols, types, imports, and structure.

02

Tour

Walk through an unfamiliar codebase in dependency order, starting with the files that make the rest easier to understand.

03

Check

Compare an explanation with the real files, symbols, and line ranges. See what is grounded and what still needs your judgment.

Built to earn trust

Your code stays yours.

SimpleeCode builds its index locally. It blocks environment and key files, redacts secret-looking lines, and limits oversized content before a prompt can leave your machine.

Prompt review is on by default. You see the complete prompt, its sources, its size, and every privacy change before choosing to send it.

Get started

Your first explanation is four steps away.

  1. Download SimpleeCode. Get the current __SIMPLEECODE_VSIX__.
  2. Install from VSIX. In VS Code, open Extensions, choose the ··· menu, then choose Install from VSIX…
  3. Open a project. Choose the SimpleeCode icon in the Activity Bar and let the local index finish.
  4. Select some code. Choose Explain Selection and review the prompt before sending.

Optional live streaming: install npm i -g @zed-industries/claude-code-acp. Without it, SimpleeCode uses a clipboard-based fallback.
