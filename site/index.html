Language support

Focused on
Swift and TypeScript...
for now

SimpleeCode’s language-aware work currently focuses on Swift—including SwiftUI—and TypeScript. JavaScript uses the same indexing path as TypeScript.

Python support is partial. Go, Rust, Java, and Ruby can be indexed when their VS Code language tools provide symbols, but they do not yet have the same language-specific explanation depth.

Install it yourself

Keep control from the start

SimpleeCode is distributed as a VSIX. The optional ACP agent streams answers into the dashboard; without it, SimpleeCode uses its clipboard fallback.

Download __SIMPLEECODE_VSIX__ ↓ Read the changelog →
  1. 01
    Download the VSIX

    Get the current signed release directly from this site.

  2. 02
    Install it in VS Code

    Open Extensions, choose the ··· menu, then select “Install from VSIX…”

  3. 03
    Add streaming if you want it

    Run npm i -g @zed-industries/claude-code-acp. This step is optional.

  4. 04
    Open a project

    Choose the SimpleeCode icon, let the local index finish, then start a tour or select code to explain.

Why it exists

Designed to show what’s being built, not just the end result

SimpleeCode started as a way to inspect AI-written projects without blindly accepting the output. It is for anyone learning their way through a codebase—or trying to judge whether generated code really does what it claims.

  • Free to use
  • Open source
  • No analytics or tracking
