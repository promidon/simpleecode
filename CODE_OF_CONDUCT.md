# Code of Conduct

## The short version

SimpleeCode exists to help people understand code they don't understand yet.
That only works if asking a basic question feels safe.

So: **be kind, especially to beginners.** Nobody here is required to already know
the thing they're asking about.

## What that means

- Assume the person asking is smart and new, not lazy.
- "Have you read the docs?" is not an answer. Point at the part that helps.
- Critique the code, not the person who wrote it.
- Disagreement is fine and useful. Contempt isn't.
- If someone says you've upset them, take it seriously rather than debating it.
- Write plainly. Jargon that isn't explained shuts people out — that's the exact
  problem this project is trying to solve.

## Not okay

Harassment, insults, or personal attacks. Discrimination or demeaning comments
about who someone is — including race, gender, gender identity, sexual
orientation, disability, neurotype, age, religion, or national origin. Sexual
attention or imagery. Publishing someone's private information. Sustained
disruption of discussions.

This applies in issues, pull requests, commit messages, code review, and
anywhere else the project happens.

## Enforcement

Report a problem privately to the maintainers through GitHub — open a
[security advisory](https://github.com/promidon/simpleecode/security/advisories/new)
if you want a private thread and there's no better channel. Reports are handled
confidentially.

Maintainers may edit or remove comments, commits, issues, and pull requests that
don't follow this, and may ban anyone for repeated or serious violations.
Maintainers who don't follow it themselves are subject to the same consequences.
